# PKHunt Scripts

Userscripts (Tampermonkey) de automação para o jogo [pkhunt.online](https://pkhunt.online).

## Scripts disponíveis

| Script | Descrição | Instalar |
|---|---|---|
| **Auto Baú** | Coleta automaticamente os baús disponíveis, com opção de auto-reload configurável. | [Instalar](https://gist.githubusercontent.com/Huddysin/7f3c3e72c80ce0b211ce0bc7353b7394/raw/Autobau.user.js) |
| **Auto Potion** | Compra poções automaticamente na NPC Maria quando o estoque fica abaixo de um limite definido. | [Instalar](https://gist.githubusercontent.com/Huddysin/44a7d1fed983a54de45c819e77f2206d/raw/Autopotion.user.js) |

## Como instalar

1. Tenha a extensão [Tampermonkey](https://www.tampermonkey.net/) instalada no navegador.
2. Clique no link "Instalar" do script desejado na tabela acima.
3. O Tampermonkey vai abrir automaticamente a tela de instalação — clique em **Install**.
4. Pronto! O script já fica ativo em [pkhunt.online](https://pkhunt.online).


## Configuração

Cada script cria um widget flutuante na tela do jogo (ícone arrastável) com um menu de configurações — basta passar o mouse sobre o ícone para abrir as opções.
